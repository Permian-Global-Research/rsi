# Get the URL to download spectral indices from

Get the URL to download spectral indices from

## Usage

``` r
spectral_indices_url()
```

## Value

A URL to download indices from.

## Examples

``` r
spectral_indices_url()
#> [1] "https://raw.githubusercontent.com/awesome-spectral-indices/awesome-spectral-indices/main/output/spectral-indices-dict.json"
```
